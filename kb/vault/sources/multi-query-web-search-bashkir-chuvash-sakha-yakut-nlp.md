## Findings

> [!warning] UNCERTAIN — turkic-other-langs-non-kazakh-turkic-nlp
> [cv][tk][sah] No dedicated from-scratch or adapted LLM/BERT was found for Chuvash, Turkmen, or Sakha/Yakut text in this sweep — these are the three languages with confirmed 'nothing found' at the model level (as opposed to corpus-only or toolkit-only coverage). Turkmen has a speech corpus (TurkmenSpeech, 251 hours / 119,847 clips @16kHz) but no equivalent text corpus/LM was located. Sakha has a Universal Dependencies treebank + morphological analyzer (YakuToolkit, SIGUL 2022) but no language model. Chuvash has only 'Open Data Chuvash' translation-pair data used inside the multi-language MT paper above, no monolingual encoder/decoder model.
>
> **Numbers:** Turkmen speech: 251h / 119,847 clips; Sakha: UD treebank + morph analyzer (SIGUL 2022), no LM found; Chuvash: 0 dedicated model found
> **Relevance:** Decision (3): these three languages are the genuinely empty cells in the Turkic NLP landscape — lowest-hanging, but also lowest-adoption-potential (very small speaker/researcher communities), targets if the lab ever wanted a 'most under-served Turkic language' artifact; NOT recommended as a first port target given the live Uzbek offer and Azerbaijani's better existing base.

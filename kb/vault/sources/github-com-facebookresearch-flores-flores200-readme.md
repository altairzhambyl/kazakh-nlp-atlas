## Findings

> [!warning] UNCERTAIN — turkic-pan-benchmarks-non-kazakh-turkic
> FLORES-200 covers 11 Turkic variants with explicit script tags: Turkish tur_Latn, North Azerbaijani azj_Latn [az], South Azerbaijani azb_Arab [az], Kazakh kaz_Cyrl [kk], Kyrgyz kir_Cyrl [ky], Tatar tat_Cyrl [tt], Bashkir bak_Cyrl [ba], Turkmen tuk_Latn [tk], Uyghur uig_Arab [ug], Crimean Tatar crh_Latn [crh], Northern Uzbek uzn_Latn [uz]. NOT covered: Chuvash, Sakha, Karakalpak, Gagauz, Altai, Tuvan, Khakas, Nogai, Kumyk, Karachay-Balkar.
>
> **Numbers:** 11/~24 Turkic language varieties covered in FLORES-200; SIB-200 and Belebele both derive their parallel passages from FLORES-200 so inherit the same 11-language Turkic ceiling
> **Relevance:** Confirms an upper bound on which Turkic languages SIB-200/Belebele-style topic-classification/reading-comprehension eval can port to without new parallel-data collection: Karakalpak (despite being in TUMLU) has NO FLORES-200/Belebele/SIB-200 presence, so Uzbek/Kazakh/Kyrgyz/Tatar/Bashkir/Turkmen/Uyghur/Crimean-Tatar are portable today, Karakalpak/Chuvash/Sakha are not without new data work.

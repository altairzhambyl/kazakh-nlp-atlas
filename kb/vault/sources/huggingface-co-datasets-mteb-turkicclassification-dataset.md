## Findings

> [!note] CLAIM — turkic-embeddings-retrieval-non-kazakh-t
> [ba][kk][ky] mteb/TurkicClassification is a currently-registered MMTEB task (topic/news classification, 80 label classes) spanning THREE non-Turkish Turkic languages simultaneously — Bashkir, Kazakh, Kyrgyz — sourced from Electrotubbie/classification_Turkic_languages on HF. 6,144 total rows (~2,050/language), license 'unknown'. This is classification only (no retrieval/STS/clustering).
>
> **Relevance:** This is the ONLY genuinely pan-Turkic (beyond Turkish+Kazakh) task presently in the official MMTEB registry found in this sweep. It proves Bashkir and Kyrgyz already have an MTEB foothold via classification, but confirms retrieval/STS/clustering for ANY Turkic language except Turkish (and Kazakh's own KazQAD/Belebele/WebFAQ, per KB) is completely absent from the registry — direct evidence for decision 3 (unclaimed pan-Turkic benchmark territory) and worth checking before assuming a 'first pan-Turkic MTEB PR' claim, since a classification precedent already exists.

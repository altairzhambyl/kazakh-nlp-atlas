## Findings

> [!warning] UNCERTAIN — turkic-pan-benchmarks-non-kazakh-turkic
> The MRL (Multilingual Representation Learning) Workshop shared tasks (EMNLP 2024/2025, 2026) are NOT Turkic-specific: 2024 task was multi-lingual/multi-task information retrieval (open to any language via community submission), 2025 shared task built a community-annotated physical-commonsense-reasoning (PIQA-style) dataset per contributed language, 2026 shared task is a community-written multimodal (audio+text) QA benchmark similar to ECLeKTic. No dedicated pan-Turkic track exists in MRL to date.
>
> **Numbers:** n/a (task format only)
> **Relevance:** MRL's 2024 IR shared task is the closest existing venue-format match to the lab's KazQAD-style retrieval work, but since Turkic languages are not a required or organized track, submitting a Kazakh (or joint Kazakh+Uzbek) entry would be a genuine unclaimed first for the pan-Turkic retrieval angle rather than joining an already-covered track.
